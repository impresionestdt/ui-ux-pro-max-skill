# claude-global

Respaldo de la configuración global personal de Claude Code (`~/.claude/`).
No forma parte del proyecto UI UX Pro Max.

Para instalar en tu computadora:

```bash
cp -r claude-global/skills/absorber-proyectos claude-global/skills/aprender-proyecto ~/.claude/skills/
mkdir -p ~/.claude/memoria-global && cp claude-global/memoria-global/*.md ~/.claude/memoria-global/
cat claude-global/CLAUDE.md >> ~/.claude/CLAUDE.md   # añade la regla sin borrar lo que ya tengas
```
